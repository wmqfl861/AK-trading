# 概率驱动策略研究第一版实施计划

日期：2026-09-08。用户授权："你按照我的需求写计划，然后开发吧"。需求来自同会话前文：用因子描述行情阶段，估计不同期限/幅度的上涨下跌概率，构造突破、回踩、价格回归和网格等策略，计算参数与净EV，再按概率选择策略。

## 交付目标

提供可以直接读取现有 futures_bundle_v1 的离线研究 CLI。输出版本化因子、价格路径标签、时间隔离的训练/校准/测试、条件概率模型、策略参数与路径净损益、条件EV及概率抽样/最高EV/固定策略/现金对照，保留原始输入/配置/代码/随机种子哈希。概率抽样是用户需求的对照方案，不能预先宣称优于确定性选择。

实际首轮使用已经冻结的RB历史输入和明确列出的具体合约，经济参数复用显式情景配置；工具支持多个合约，但不把不同合约独立账户简单相加成可执行组合。历史严格规则认证和实盘下单不在本轮。

## 公共接口与测试边界

本轮测试边界由实际交付能力确定：

1. `build_factor_rows(contract_id, symbol, product, bars)`：可版本追踪的因子注册表和逐前缀记录。前高/前低排除当前bar；ATR、ER、z-score、均线、波动、量仓不读取未来。
2. `label_paths(observation, bars, scenario)`：已知ATR尺度、下一观察开盘为参考进入价、上下障碍、1/5/20根期限；先上/先下/未达/同bar双达先后不明；尾部未成熟与中间坏数据不能当作未达。
3. `fit/predict`：只用训练集拟合；用单独校准集确定温度，最终测试只评估。条件频率＋平滑/回退是可解释基线，预测未来状态和障碍结果，报告 Brier/log loss/可靠性及样本数。
4. `simulate_action`：突破、回归、回踩确认、有限库存网格及现金的事件级完整持仓损益。所有进出可复算费用/滑点/保证金，不能把未来收益当成决策输入。
5. `fit_payoffs/route`：条件净EV、盈利概率、尾部损失、保守惩罚和选择。用户阈值/样本量不满足则现金；概率抽样固定种子，最高EV/固定策略同机会对比。
6. 冻结输入至CLI输出：严格参数/身份/哈希检查、新目录发布、确定性重放；新鲜度检查只读数据库，过期与空数据返回非零。

每个模块使用公共行为测试先失败再实现；核心标签和损益用手工可核算路径。无需重复运行过去无变化的大套件，每个模块集中验证后最终运行完整离线回归。

## 数据与统计口径

- 所有输入保持具体合约完整实例身份，不拼接主连，不伪造交易时段。原始时间戳用于跨合约全局时间排序；期限是存储观察根数。
- 使用全数据全局时间的60%训练/20%校准/20%最终测试分区。每个事件的完整最长标签和策略窗口必须落在同一分区，否则显式purged；不随机拆行。
- 训练与校准阶段内部标签重叠仍有依赖，报告说明；策略对照在每个合约使用固定不重叠事件间隔，不汇总成跨合约组合权益。
- 价格路径概率包括同bar上下双触的 ambiguous 概率，不将其丢弃后重新归一化制造确定性。另估计未来上涨趋势/下跌趋势/区间状态，其标签定义固定并与当前启发式状态分开。
- 因子位置包括接近前高/前低和中间区域，未来幅度按决策时ATR尺度并同时记录点数；多期限与障碍参数显式登记。
- 条件频率模型和收益模型保留稀疏回退及校准不足状态。保守EV的标准误惩罚只是风险启发式，不冒称独立样本置信区间。
- 固定经济假设不是历史官方参数，成本/滑点/保证金来源保持可见。最终留出一经使用即 consumed，真实实验仅作研究，不调参追求正结果。

## 策略口径

- 突破：决策时对已知前高/前低的突破，下一观察开盘入场。
- 价格回归：由z-score/区间位置确定方向，下一开盘入场。
- 回踩：已形成趋势后，未来窗口中的已完成收盘满足已冻结回踩水平，下一开盘入场；不伪造盘中限价顺序。
- 网格：以决策价和ATR冻结网格水平，根据日线收盘确认的偏离调整目标库存，下一开盘成交；固定单级手数、最大级数和止损，无马丁加倍。它是日线收盘确认网格近似，不冒称盘中真实挂单网格。
- 普通策略止盈止损遇同bar双触采用预先固定的止损优先保守规则并计数；跳空止损按更差开盘价，终止按预定窗口末收盘并计成本。

## 实施分工

A 因子注册与标签；B 事件级策略/网格损益；C 条件概率/校准/收益模型；D 选择和非重叠对照；主代理类型契约、时间切分、CLI/文档/真实实验；E 数据新鲜度检查。开发文件独占。完成后两组独立审核重点检查因果与统计，以及会计/发布/数据边界。
