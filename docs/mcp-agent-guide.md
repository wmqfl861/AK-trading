# AK 行情数据 MCP 使用说明(给 AI agent)

你通过 MCP 服务 `ak-market-data` 访问中国期货历史行情数据库(只读,写入物理不可能)。
端点 `http://114.66.31.43:17779/mcp`,需要 Bearer Token 鉴权。

## 推荐工作流

1. `get_trading_calendar(start, end)` — 确认哪些天是交易日(周末/假日无数据,不是缺失);
2. `get_coverage(symbols)` — 确认目标符号数据到哪天(通常到最近一个交易日);
3. `search_symbols(pattern)` — 不确定符号名时前缀搜索;
4. `get_daily_bars` / `get_minute_bars` — 取数;
5. 需要成本核算时用 `get_settlement_reference(day, symbol)` 查官方保证金率/手续费。

## 符号规则(必读)

| 类型 | 格式 | 例子 | 有日线 | 有分钟线 |
|---|---|---|---|---|
| 具体合约 | `交易所.品种+月` | `SHFE.rb2610`、`DCE.i2609`、`CZCE.TA609` | ✅ | ✅ |
| 主力连续 | `KQ.m@交易所.品种` | `KQ.m@SHFE.rb` | ❌ **没有日线** | ✅ |
| 指数(加权) | `KQ.i@交易所.品种` | `KQ.i@SHFE.rb` | ✅ | ❌ |
| 期权(上期/大商/郑商/广期) | `合约+C/P+行权价` | `SHFE.rb2610C3200`、`CZCE.CF611C17000` | ✅ | ❌ |
| 期权(中金所,有连字符) | `合约-C/P-行权价` | `CFFEX.HO2609-C-2500` | ✅ | ❌ |

CZCE 三位月份:609=2026年9月,701=2027年1月。搜索前缀至少 6 字符、禁通配符。

## 时间语义

- 所有日期参数 ISO `YYYY-MM-DD`,时间戳为北京时间;
- **夜盘属于下一交易日**:周五 21:00-周六 02:30 的分钟线 `trading_day` 是下周一;
- 股指/国债(CFFEX)无夜盘,15:15/15:15 收;商品多数有夜盘(21:00 起);
- 有夜盘品种当日分钟线最后时间戳约 22:59-02:29,没有不代表数据缺失。

## 已知数据边界(别得出错误结论)

1. **DCE 会员排名 2026-09-11 起暂缺**:交易所披露系统故障,其他 5 所正常;单日用 `get_member_ranks` 查 DCE 返回空属已知状况;
2. **2016-2018 年部分品种分钟线存在历史缺口**(数据源限制),做长回测前先用 `get_coverage` 或抽样验证;
3. INE 的 sc/ec 品种交易所不披露排名,空结果是正常的;
4. 结算参数里官方费率 `ratio` 标记 `unit_unverified` 时**不要**直接当费率计算,优先用 `flat`(元/手)或参考源;
5. 结算参数的"可用"指本地有快照,不等于经纪商实际收费。

## 效率与限额

- 每 IP 每分钟 120 次调用,超限 429(等 1 分钟);
- 分钟线单次 ≤31 天且 ≤6000 行,响应 `truncated: true` 时缩小窗口分批;
- 大范围分析优先用日线/主连分钟线,不要逐合约扫分钟线;
- 批量取数前先 `get_coverage` 过滤掉没有数据的符号。

## 常见错误

- 用自然日当交易日(周六日查不到数据就以为缺失)→ 先查日历;
- 给 `KQ.m@` 查日线 → 它只有分钟线;
- 给期权查分钟线 → 期权只有日线;
- 分钟窗口一次拉 3 个月 → 会被拒绝,按 31 天分批;
- 猜合约名(如 SHFE.rb2612C9999)→ 先 `search_symbols` 确认存在。
