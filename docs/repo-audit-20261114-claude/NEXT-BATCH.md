## 一、这一批要回答的两个问题

1. v2 的方向预测模型在真实的螺纹钢数据上拟合之后，对没见过的时段，是否比“只报历史占比”预测得更准（K45-R001）。

### K45b 工具、测试、阶段一、阶段二、预演

**写集**（由计划作者确认）：`tools/experiments/` 下的新工具，`tests/experiments/` 下的测试。如果 J34 选的是修改拟合入口，另加 `src/ak_trading/v2/probability/models.py` 和对应测试；那样的话把 REVIEW 的 Z26 一并修掉（J39）。

**约束**（沿用设计 §3、§7）：只调用生产函数，不复制因子、标签、拟合、温度的公式；不经过 M5 的正式实验入口；不登记留出集；输出不含行情明细；结果标 `SCENARIO / NOT_ASSESSED`。

**合成测试至少覆盖**：设计 §7 列出的各项，加上本轮新增的四项。

1. 差分测试：只拟合方向得到的方向模型，与全部任务一起拟合时逐位相同（算法、参数、温度）。
2. 可用时刻的情景口径只改写了该改写的行；在这个口径下，节内取样得到的特征快照是可用的。
3. 阶段一、阶段二的代码路径读不到检验段的标签。
4. 预演用的切分与正式切分走同一套代码，只是日期不同。

**阶段一的产物**（不读检验段的标签和价格变动）：

- 漏斗表。每个模式、每一段（训练、校准、检验）一行：候选决策时刻 → 特征快照可用 → 生成了预测请求 → 标签成熟 → 进入方向样本，以及各自覆盖的交易日数。每一步写明丢掉多少、最多的三个原因。检验段只填到“生成了预测请求”。
- 耗时表。特征、请求、标签三步在训练段上的实测单位耗时，和按它外推的全程耗时。

**阶段一的停止点**：

| 情况 | 处理 |
| --- | --- |
| 某个模式的训练段达不到生产默认的内层门槛（拟合 120 天、验证 30 天） | 这个模式记 `INSUFFICIENT`，停在阶段一。另一个模式继续 |
| 某个模式的检验段里，有预测请求的交易日不足 60 | 同上 |
| 两个模式都停 | K45 停在阶段一。写明原因，不改设计 |
| 外推的全程耗时超过 72 小时 | 停下报告。不改取样 |

**阶段二的产物**：方向模型和两个对照的哈希；每个期限选中的算法、温度、四个候选在内层验证上的损失；预演的摘要（只写“跑通了没有、各步的数量、有没有异常大的数”，不写进结论）。

**独立硬审**：工具、测试、阶段一和阶段二的产物、预演的输出。重点是时间上的泄漏：检验段的任何信息有没有可能进入拟合、行情状态参考、标准化、选算法、定温度。无条件 PASS 才进入阶段三。

## 四、支撑线

### K46 六品种报告第二版

**目标**：让这份报告能被直接读懂，并补上三样现在没有的东西。不新跑回放，不调参数。

**输入**（只读，都已通过独立审核）：六个品种已验收的逐日账本、选约序列、每个账户每天的规则状态；冻结的日线输入（取前一根收盘价和合约乘数）。

**内容**：

| 部分 | 做法 |
| --- | --- |
| 第一屏 | 按下面的写法，数字从 CSV 取。事实与写法不符的地方按事实改，不超过五句 |
| 总表 | 每行一个品种和做法。列：主力口径净额（元，取整，带千分位）；相当于一手名义金额的百分比；为正的年数；最差的年份和金额；最大回撤；规则就绪覆盖率；主力口径下的开仓次数 |
| 按名义金额折算 | 每天：主力口径净额 ÷ 当天主力合约一手的名义金额（前一根收盘价 × 合约乘数）。全期和分年按天相加，不复利。最大回撤用百分点表示 |
| 合并口径 | 每天把各品种折算后的数等权平均，只算当天有主力合约的品种。五种做法各一条：全期、分年、最大回撤、最长回撤天数。每天参与平均的品种数写进 CSV |
| 规则就绪覆盖 | 每个品种、每个规则：主力日里规则已经过了预热的天数占比；主力口径下的开仓次数；从未开仓的合约数。覆盖率低于 50% 的“品种 × 规则”在总表里标明，不进合并口径，也不计入“几个赚几个亏” |
| 资金门槛 | 一张小表：每个品种在四档资金下的开仓尝试、成交、被保证金拦下的次数。代替现在 375 行的情景表，那张表只留在 CSV 里 |
| 限制 | 没有换月成本；指标只用单个合约自己的历史；没有统计检验；合并口径不是一笔资金连续运行的结果 |

折算和合并的精确定义（缺前收盘价的那一天怎么处理、工业硅上市前按几个品种平均）由计划作者确认后写进报告。

**第一屏的写法**（花括号里的数从 CSV 取）：

```text
六个品种、三个规则，2020-07 至 2026-09，每个合约固定 1 手，规则和参数没有调整。
三个规则没有显示出稳定的优势：只按主力合约算，{n} 个“品种 × 规则”里 {a} 个赚、{b} 个亏，好过一直持有主力合约的有 {c} 个。
把各品种折成同样的名义金额合在一起，全期合计：突破规则 {x}%，均线 {y}%，回归 {z}%，一直持有 {w}%。这不是年化收益率。
{品种}上规则大部分时间在等 K 线攒够，只有 {p}% 的主力日能出信号，没有计入上面两句。
这些数字没有扣换月成本，指标只用单个合约自己的历史，也没有做统计检验；它们的用处是当基准线。
```

**交付**：`docs/research/v1-daily-baseline-universe.md` 改为第二版；新增的 CSV；`CHECK.json`。螺纹钢的单独报告不动。

**验收**：独立审核者从同一批源文件独立重算，表格逐格相同；折算后的分年之和等于全期；`new_simulation=false`、`holdout_read=false`；`CHECK.json` 里登记的工具、配置、测试文件哈希等于仓库里的文件；仓库外文件的清单只入库哈希和文件数（J40）。

**不做**：不调参数，不增减品种，不新跑回放，不做“统计上显著”之类的表述，不把未折算的金额跨品种相加。
