## v3 与 v2 的区别

v2 的四个阶段只落实了阶段 0 的一半，研究交付没有开始。v3 做三处调整：

1. **关键路径只留一条**：T7 DAILY → RB DAILY 报告 → MINUTE 性能 → T7 MINUTE → RB MINUTE 报告 → 本地 paper。N8、DISPATCH、完整 ordinary shadow 暂停到第一份 DAILY 报告之后。
2. **先修实测热点和运行方式，再推进功能**：`visible_bars` 热点先修；冷链验收拆出测试夹具；长测试可续跑，工程运行可重试，路径要短，CI 先上线。
3. **并行收窄**：关键路径上 1 条开发线加 1 条审核线，另留 1 条支撑线做 CI、路径和工具。
