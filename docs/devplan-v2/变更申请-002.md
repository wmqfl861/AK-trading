## 2. 冻结签名与校准连接

```python
def build_calibration_evidence(predictions: tuple[MarketForecast, ...],
                               labels: tuple[PathLabel, ...],
                               block_ids: Mapping[str, str],
                               policy: ConfidencePolicy, as_of_nano: int,
                               valid_until_nano: int, *,
                               features: tuple[FeatureSnapshot, ...]) -> tuple[CalibrationEvidence, ...]: ...

def calibration_geometry_key(features: FeatureSnapshot, frozen_range: FrozenRange | None,
                             event: str) -> str | None: ...

def predict_market(models: ForecastModelSet, request: ForecastRequest,
                   regime: RegimeAssessment,
                   published_at_nano: int) -> MarketForecast: ...
```

features没有默认值；原有六个位置参数保持顺序。标量/无区间事件同样必须提供真实快照，禁止可选features、隐式缓存、合成shim、从forecast猜tick或四桶加占位符。

1. predictions的forecast_id与request_id分别唯一；features的snapshot_id唯一，键集恰为predictions引用的snapshot_id集合。同一快照可被多个期限/障碍请求引用，元组中不重复放置快照。重复ID即使字节相同也拒绝；输入顺序不决定连接。
2. 按snapshot_id连接后，逐项核对contract_id、product、trading_day、session_id、session_kind、duration_seconds、decision_nano、reference_price及atr_points。快照与所需元数据必须在decision时已可见。fit_forecast_models还须校验calibration_requests中的完整request.features等于该快照。
3. labels按request_id一一连接；labels和block_ids的键集均恰为本次predictions的request_id集合。标签contract_id、horizon、window_start/end、label_version、range_id精确匹配预测。连接重复、缺失、多余或字段错配报ValueError（允许M3A本地子类），不能静默丢行。block_ids禁止缺键后猜日期块，沿用既有交易日期分块规则。
4. 完成结构与身份检查后才排除INVALID/迟发预测和非MATURE标签。published不得晚于as_of；MATURE标签的available_at必须存在且不晚于as_of。valid_until须晚于最晚校准输入可见时点，既有训练/校准隔离不变。调用者保留排除审计，不将无效行记为成功、NEITHER或新增独立样本。predictions、labels、features及block_ids全部显式为空时才允许空features并返回空证据。
5. fit_forecast_models从已有calibration_features/calibration_requests取得输入，对本次预测选择精确对应的快照、标签、日期块，并在ordinary/martingale两次调用均传`features=...`。COMMON去重仍在合法连接之后，三种障碍不能把同一事件变成三份独立支持。

每个适用的区间/突破/STOP_TOUCH/RETURN_BEFORE_BREAK事件，用连接快照及prediction.frozen_range调用M1函数；缺几何输入返回None时拒绝生成该证据。M3A预测须与原request逐字段保持完整FrozenRange、锚、障碍、窗口和期限一致；M3B/M4消费时继续与实际setup/budget精确核对。相同range_id或geometry_key不构成豁免。

## 3. C与五桶的唯一解释

C=`features.reference_price`，ATR=`features.atr_points`，L/U/止损来自传入FrozenRange，W=U−L。M=`FrozenRange.center`仅为冻结回归目标。旧区间沿用时，range.source_snapshot_id可不同于当前snapshot_id，frozen_at不得晚于decision；C可以偏离M甚至位于L/U外，不移动边界或裁剪C。

五个量固定为`W/ATR, (C−L)/W, (C−stop_lower)/ATR, (stop_upper−C)/ATR, tick/ATR`，分界与端点规则沿用M1 §4.1。tick只取该快照唯一、有效且在decision前可见的`META:price_tick:v2.1.0`正有限Decimal；重复元数据键报错，缺失/失效不猜值。五个编号以`-`连接，键为`geometry-v2.1.1|<event>|b0-b1-b2-b3-b4`；非区间事件末尾仍为`ANCHOR_ATR`，也使用新版本。

几何函数event参数将`PERSIST:<E>`映射为E，`STOP_TOUCH:LONG/SHORT`映射为`STOP_TOUCH`，其余原样；CalibrationEvidence.event继续保留完整事件名及LONG/SHORT，不合并两侧概率证据。

手算：固定L=98、M=100、U=102、stop_lower=96、stop_upper=104、ATR=2、tick=0.1。C=99时五个量为`2, 0.25, 1.5, 2.5, 0.05`，桶为`1-2-2-3-2`；C=100时桶为`1-3-3-3-2`。STOP_TOUCH键分别为`geometry-v2.1.1|STOP_TOUCH|1-2-2-3-2`和`geometry-v2.1.1|STOP_TOUCH|1-3-3-3-2`。冻结同一区间不能把两者强制配成中点桶。

## 4. 迟发记录与消费者规则

所有记录均检查输入可见性、`decision<=published`、`decision<window_start<window_end`、身份/类型/价格/概率/分位数/完整range。只有以下分支不同：

| published位置 | 质量与expiry |
| --- | --- |
| `< window_start` | 非迟发，不能带FORECAST_LATE；`published<expires<=window_end`，分钟/日线TTL及模型准入截止按原规则 |
| `window_start <= published < window_end` | 必须INVALID且reasons含FORECAST_LATE；expires=原window_end |
| `published = window_end` | 同上，expires=published，作为审计记录合法 |
| `published > window_end` | 同上，expires<published，作为审计记录合法 |

迟发必须保留原request_id、snapshot_id、decision、window、horizon、reference_price/ATR、障碍、完整FrozenRange及真实published。仅迟发分支豁免`expires>published`，不豁免其他检查；普通INVALID或只写reason但status不为INVALID不得借此绕过校验。迟发状态优先于STALE/DEGRADED，其他诊断保留在reasons。迟发expiry统一取原window_end，不再按published延长或按模型期限裁剪；它从产生起就没有准入资格。

predict_market的迟发结果只能是该公共MarketForecast，不采用ForecastLateError/LatePublication作为另一种跨节点协议。构造及JSON解码须接受合法迟发记录，概率/价格非法等其他错误仍拒绝。非迟发记录伪标FORECAST_LATE、伪造窗口或用概率空结构绕开类型契约均不能通过。

M3A校准、M3B候选/准入、M4经济准入/回放、M5评分排除INVALID预测，禁止用其OPEN/ADD；既有REDUCE/EXIT风险通道不变。M5在标签成熟检查之前按原request_id统计FORECAST_LATE发布失败，写入既有exclusions字典，不计正常预测n、blocks、Brier/ECE/其他得分。迟发不计on_time_forecasts，expected_forecasts保持原预登记网格/请求分母；缺发也不能删分母，同一预登记请求的重试/重启最多计一次，不靠新窗口抹除原失败。完整迟发记录继续写既有forecasts.json/forecasts.jsonl，不新增不兼容诊断记录类型。
