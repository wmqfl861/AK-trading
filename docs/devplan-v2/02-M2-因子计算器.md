### 4.1 参数与身份冻结

源定义已实际核对：MOM001=`sum(r,n)`；MOM003=`sum(r,n)/(std(r,n)*sqrt(n))`；MOM010 带方向；REV001 公式 k 与参数 n 不一致；VOL004 为 Wilder ATR；VOL005 为年化负收益平方均值；VOI001 排除当前均量；VOI009 为即时 V/OI。

`factor_key` 精确格式：`<source_factor_id>:v2.1.0:d<duration_seconds>:<parameter_version>`。例如 `MOM010:v2.1.0:d60:m1-n60`、`MOM010:v2.1.0:d86400:d1-n20`。分钟不同输入周期分别用 `m1/m5/m15/m30/m60` 前缀；初始每个分钟频率的 n=60、日线 n=20，参数版本分别 `m1-n60/m5-n60/m15-n60/m30-n60/m60-n60/d1-n20`。n 是该频率完整 bar 数，预测期限仍是交易分钟/日，二者不可互换。

REV001 明确采用 `k:=n` 的别名解释，不擅改原定义；分钟 k=60、日线 k=20，在参数中同时记录 `{"n":60,"k":60,"alias":"k_equals_n"}`。训练阶段可比较源预登记 n=20/60/120，但每个版本单独输出、全部试验登记，测试后不改默认窗口。VOI009 无回看窗口，参数版本为 `m1-instant/m5-instant/m15-instant/m30-instant/m60-instant/d1-instant`，lookback=1，不制造无效 n 版本。

`parameters` 每项必须显式包含 `return_kind`, `std_ddof`, `include_current`, `window_unit`, `annualization`, `annualization_factor`, `session_boundary`, `zero_policy`，不适用值用字符串 `not_applicable`。收益 `r_t=ln(C_t/C_{t-1})`；std 使用样本标准差 ddof=1；价格和 volume/OI 不用 float 硬取整。

分钟主版本年化采用 `annualization="PER_BAR", A=1`，避免把日线 252 直接当一分钟年化尺度。日线主版本 `annualization="NOMINAL_252", A=252`，标明名义尺度。将来分钟年化版本只有在品种历史会话模板已核验时可登记：`A=252×Σ_j floor(连续会话分钟数_j/频率分钟数)`，参考模板和日历版本在训练期冻结，不使用未来实际成交分钟数推算。该新参数版本不能覆盖主版本。

跨合法会话的连续合约收盘收益含会话间跳空，标记 `session_boundary="INCLUDE_GAP"`；因子窗口可跨合法休市累积完整观察，但不能跨缺失槽或换合约。日内季节性在此原始序列之外生成另列，不改变原公式。源无输入值、预热不足、零方差、零分母分别为 MISSING/WARMUP/INVALID 或 DEGRADED，原因必须区分。

### 4.2 十项公式的精确实现

设 t 为已完成且可见的当前 bar，P=C，V 为该 bar 成交量，OI=close_oi。

| 因子 | 精确计算 | 最少输入与边界 |
| --- | --- | --- |
| MOM001 | `Σ_{i=t-n+1..t} ln(C_i/C_{i-1})` | n+1 收盘，要求正价；不跨合约相除 |
| MOM003 | MOM001 / `(sample_std(r,n)×sqrt(n))` | n+1 收盘；n≥2，std=0 返回 None，不给无穷趋势 |
| MOM010 | `(C_t-C_{t-n})/Σ_{i=t-n+1..t}|C_i-C_{i-1}|` | n+1；范围 [-1,1]，总路径=0 返回 None；绝对值只作为另行命名的强度 |
| REV001 | `-Σ_{i=t-k+1..t}r_i`，k=n | k+1；不能误写为当前 z-score 或隐含负号两次 |
| VOL001 | `sample_std(r,n)×sqrt(A)` | n+1；std=0 可明确输出 0 风险观测，但不得因此产生无风险交易资格 |
| VOL004 | `WilderATR_n(t)/abs(C_t)` | n+1 起种；TR=max(H-L,abs(H-Cprev),abs(L-Cprev))；最初 n 个 TR 算术均值为种子，随后 `(prevATR×(n-1)+TR)/n`；C=0 无效 |
| VOL005 | `A×Σ min(r_i,0)^2/n` | n+1；分母 n 含非负收益项，不只对下跌项求均值，不开方 |
| VOI001 | `V_t / mean(V_{t-n}..V_{t-1}) - 1` | n+1 个量，参考窗排除当前；分母0无效，V_t=0且分母>0得 -1 |
| VOI007 | `OI_t/OI_{t-n}-1` | n+1 个 OI，不跳过中间缺失；分母0无效 |
| VOI009 | `V_t/OI_t` | 1；OI_t=0无效，不解释为净多资金流 |

Wilder 为递归状态：坏行或应有分钟缺失时重置，重新积累完整 n 个 TR 才可输出；不能删除坏行继续递推。追加未来行不会改变已计算种子或历史输出。

### 4.3 十四项基线与季节性

旧日线十四项为 `close,prior_high20,prior_low20,atr14,er20,vol20,ma20,ma60,ma_spread_atr,zscore20,distance_high_atr,distance_low_atr,volume_ratio20,oi_change5`。v2 基线键精确为 `BASE:<name>:v2.1.0:d<duration_seconds>`，其公式保持旧窗口含义；适配旧日线输出时另保存对照标签 `legacy-v1`，不得重标成新 Alpha。所有策略引用这些键时必须包含周期。

关键区别必须在注册产物中可见：ER 为绝对值；ATR14 为算术 TR 均值；vol20 为简单收益样本标准差且未年化；zscore20 参考此前20根、排除当前；前高/低排除当前；量比无减1；OI变化为5根。分钟基线重新实现同口径计算，不能通过修改旧类型允许分钟。

不在前缀中混入不同 duration。生成高周期背景时分别形成对应快照，再以合法 available_at 做 as-of 关联。`daily_background_id` 只指向此前已完成交易日的快照。

同一 duration 的返回集合由原十四项增加为十五项，新项精确键为 BASE:opening_gap_points:v2.1.0:d<duration_seconds>，duration 仍仅 60/300/900/1800/3600/86400。原 registry 组合入口继续履行原职责；发布的 factor_registry.json 必须包含新项与原登记项，禁止在快照里私加未登记行。v1 legacy_daily_baseline 和对照报告继续只有原十四项，不为新项伪造旧值。

新 FactorSpec 的固定字段如下，其余已有 FactorSpec 类型规则保持：

| 字段 | 值 |
| --- | --- |
| factor_key | BASE:opening_gap_points:v2.1.0:d<duration_seconds> |
| source_factor_id | BASE:opening_gap_points |
| operator_version | opening-gap-v2.1.0 |
| parameter_version | session-pair-v1 |
| duration_seconds | 当前登记周期 |
| lookback | 2，表示两个价格端点，不是取最近两条存储行 |
| unit | price_points |
| required_fields | ("open", "close")，分别作用于当前会话首 bar 和前会话收盘 bar |
| formula | session_open - prior_session_close |
| source_sha256 | 下方完整本地定义对象 D 的规范 SHA-256 |

parameters 精确为：

```json
{"return_kind":"not_applicable","std_ddof":"not_applicable","include_current":true,"window_unit":"SESSION_PAIR","annualization":"not_applicable","annualization_factor":"not_applicable","session_boundary":"IMMEDIATE_PREVIOUS_SESSION","zero_policy":"KEEP_VALID_ZERO","value_scope":"CURRENT_SESSION","prior_close_anchor":"EXACT_SESSION_END"}
```

两个价格端点可能不在当前滚动尾窗内，故 M2 必须按完整已授权前缀和显式 sessions 查找，不能以 bars[-2:] 实现本项；当前目标 bar 的身份/完成证明也属于实际依赖。此参数定义不改变原十四项 lookback 的滚动含义。

**分钟定义。** 先按 005 的应有网格和 PIT 规则确定本周期当前目标完整 bar a 及其连续 SessionWindow W。b0 必须是 W.start 起的第一个计划完整同周期 bar，不能以“第一条实际找到的 bar”替代。P 是同 product 完整日历中紧邻 W 之前的开市片段，不按自然日、同 DAY/NIGHT kind 或最近有数据的片段猜测；合法休市可以跨过，已声明而缺行情的片段不能跳过。c 必须为同 contract_id/product/duration、恰以 P.end 结束的完整收盘 bar。P.end 不得晚于 W.start；当前与前会话身份均须核验。

**日线定义。** W 是 a.trading_day 的虚拟完整日会话，身份沿 02 的 DAILY:<product>:<YYYY-MM-DD>；b0=a，session_open=a.open。P 是完整日历上紧邻的前一个开市 trading_day，c 是该日完整可见的同合约日线，结束锚为该日最后计划会话结束。86400 只是频率标识，不能按自然 24 小时找前一天。该值只能在当前日线完成并可见后用于日线决策；盘中仍不能读取本交易日最终日线。

只取 b0.open 与 c.close 两个正、有限 Decimal 价格，gap=b0.open-c.close，单位为价格点数，有符号，可以为零。不得用 a.close、当前 bar.open、前一存储行 close、settlement、前合约或主连替代。两个源 bar 及当前目标 a 必须 complete=True、end<=decision、available_at 已知且 <=decision，遵守原字段质量规则；缺量/OI 不使合法价格差失效。

高周期前会话有不足一根的尾段时，不能将更早的完整高周期 close 冒充 P.end 收盘；若没有符合上述条件的 c，本项 MISSING。不得跨午休拼 bar、把 incomplete 尾段改为 complete，或在未声明接口下混入较低周期来源。该可用性限制在 M5 分频率报告，不能为覆盖率改锚。

同一 W 的后续完整 bar 继续输出同一 b0.open-c.close，合法则 READY；这是会话属性，不是一次性脉冲。当前 a 缺失不可回退旧锚；新 W 尚无完整可见首 bar 时，不能借前 W 的快照/跳空宣称新 W 开盘已知。第一次可用时点至少是 b0 与 c 均完成、可见的时点。

**质量语义固定如下。** 始终保留登记行；不增加 NOT_APPLICABLE 等公共枚举。

| 情形 | value / status / 必须保留的原因 |
| --- | --- |
| 合法首 bar，或同会话后续合法 bar | 真实 Decimal gap / READY；后续值仍是原会话开盘差 |
| 合法同价开盘 | Decimal("0") / READY；这是已知零差 |
| 首个计划 bar 或其 open 缺失、未知首见、未完成或未到可见时点 | None / MISSING / session_open_missing |
| 紧邻前会话收盘或其 close 缺失、未知首见、未完成或尚不可见 | None / MISSING / prior_session_close_missing |
| 当前目标观测缺失 | None / MISSING / expected_slot_missing |
| 无完整日历/覆盖证明或相关日历 UNKNOWN | None / MISSING / calendar_unknown |
| 同时可见冲突、错合约/周期/槽、日历结构冲突、非正/非有限价格 | None / INVALID / 对应明确原因，如 opening_gap_identity_mismatch、opening_gap_price_invalid；原冲突原因一并保留 |

首个输入时期缺前会话收盘也按上述 MISSING，不用普通滚动 WARMUP 掩盖具体缺项。普通十四项的 WARMUP 行为不变。多个缺项合并原因；INVALID 不被 MISSING 覆盖。尚未可见的未来内容先过滤，不使此前快照冲突或改变历史 hash。后来真正可见的补齐只影响后续决策，不能回写旧值。

READY 行的 available_at 取实际消费 b0、c、a 的 available_at 最大值（去重同一 bar），不晚于 decision；不取 imported_at、不补造首见。缺失行不得伪造未知源的可见时点，按 005 保留未知及原因。quality.input_hash 依 005 绑定完整实际 spec、实际源 bar 内容、目标锚、两会话及决定紧邻/缺失的必要日历证据；snapshot 身份、source_bar_ids 也须包含实际依赖。整包未来数据只在运行 manifest 溯源，不进入历史身份。

令 H(x)=SHA256(M1.canonical_json_bytes(x))。本新项是本地 BASE 定义，没有 v1 同名因子，也没有库内 23 字段原件。其 source_sha256=H(D)，六频率共享如下完整 D；频率/参数差异由完整 FactorSpec 与 operator_hash 另行绑定：

```json
{"definition_id":"BASE:opening_gap_points:v2.1.0","operator_version":"opening-gap-v2.1.0","formula":"session_open - prior_session_close","unit":"price_points","minute_session":"continuous_SessionWindow","daily_session":"complete_trading_day","current_open":"first_planned_complete_bar_open","prior_close":"same_duration_bar_ending_at_immediate_prior_session_end","later_bars":"same_session_gap","availability_policy":"complete_and_PIT_visible","missing_policy":"MISSING_with_reason_no_fallback","calendar_policy":"M1_and_change_005"}
```

D 是本申请正式定义原件，由 M2 纳入新 run 可核验来源，不能伪称 FactorLibrary 原记录。005 的 spec_hash、parameter_hash、operator_hash 和完整 bar 输入哈希要求继续适用。原十项库因子的原始 23 字段对象及 source_sha256 算法完全不变；新增一个 BASE 不是修改库内 23 字段原件的理由。

季节性桶按 `product + session_kind + slot_index + duration_seconds + calendar_version` 区分夜盘、早盘、各自开盘阶段。fit 只用训练时间窗且每个桶每交易日最多一条，至少20个训练日；缺桶不混用另一个品种。输出两列精确 ID 为 `SEASONAL:volume_relative:v2.1.0:d<duration_seconds>` 和 `SEASONAL:abs_return_relative:v2.1.0:d<duration_seconds>`，分别为当前量/历史同槽中位量−1、当前绝对收益/历史同槽中位绝对收益。零分母与不足20日为缺证据，不补1。首分钟隔夜跳空单列桶，不把夜盘开盘与下午连续分钟混合。标准化模型在一个验证折内冻结，不随测试期推进重拟合。

## 7. 测试与验收标准

- **手算 MOM001/REV001**：n=2，收盘100、110、121；累计动量=`ln(1.21)`≈0.1906203596，反转为其负数；MOM003 分母为0须 None。另用100、110、99得到 r1=ln1.1、r2=ln0.9，以 `(r1+r2)/(abs(r1-r2))` 核对 n=2 的归一动量。
- **手算 ER**：收盘100、102、101、105，n=3，signed ER=5/7；反向序列105、101、102、100得−5/7，绝对值一致；完全不动无定义。
- **手算 Wilder**：n=3，TR=2、4、6，种子4；随后TR=8，ATR=16/3；当前收盘100时 VOL004=0.053333…；算术最近三项=6，必须证明两者不混用。
- **手算半方差**：注入纯收益序列−0.1、0.2、−0.3，A=1，VOL005=1/30；A=252 得8.4，不能开根号。公开计算器另从正价构造同收益序列验证。
- **手算量仓**：此前3根量10/20/30、当前40，VOI001=1；同窗旧量比=2。OI从100到110，VOI007=0.1；V40/OI110=4/11。VOI009 改 n 不产生新输出。
- **z-score边界**：以前窗20值与含当前20值分别手算，旧基线使用前窗；新十项中没有冒名 z-score。前高/低不包含当前突破 bar。
- **因果性**：同一输入前缀构造快照，追加未来100根、极端量、晚到日线，原时点全部 snapshot/hash/value 不变。冻结季节性模型在追加测试期极值后不变。
- **会话与跨合约**：午休/夜盘合法相邻观察允许收盘跳空收益；应有缺失分钟使窗口重新预热；主连切换、相同 symbol 不同 contract_id、聚合尾段均不能静默合并。
- **数据边界**：不够n+1、n=1标准差、非正价、缺高低、volume/OI为空或负值、0成交量、0持仓、无变化、极大Decimal和非有限float。量仓缺失不污染可计算价格因子。
- **季节性手算**：20个训练日同槽成交量全部10、当前20，relative=1；另夜盘同槽100不得混入；fit_end之后数据不可入拟合，训练期不足20日为缺证据。
- 价格/量/OI Decimal计算精确；纯浮点统计手算允许绝对误差1e-10、相对误差1e-9。单位和空值原因必须同时通过，不以浮点近似掩盖公式差异。
