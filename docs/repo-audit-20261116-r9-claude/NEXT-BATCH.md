### 3.3 问题一：有没有方向信息

记模型给的三类概率为 涨 p₁、跌 p₂、持平 p₃，实际结果为 y。

1. 对数损失拆成两部分。
   - 会不会动：y 是持平时取 −ln(p₃)，否则取 −ln(p₁+p₂)。
   - 往哪边动：y 是持平时取 0；y 是涨时取 −ln(p₁/(p₁+p₂))；y 是跌时取 −ln(p₂/(p₁+p₂))。
   - 两部分相加就是原来的 −ln(p_y)。逐行核对，偏差不超过 1e-12。
2. 对模型、原始对照、调温对照各算这两部分的日均损失。改进 = 对照的损失 − 模型的损失。报三个数：会不会动的改进、往哪边动的改进、合计。合计应当等于 `main.csv` 里 `raw_logloss − model_logloss`。相对调温对照的同样三个数也报。
3. 偏多组和偏空组。概率差 s = p₁ − p₂。s 大于 0 的行是偏多组，小于 0 的是偏空组，等于 0 的不入组（报行数）。每行的权重是 1 ÷ 当日行数。
   - 涨跌占比之差：每组内算加权平均的（y 是涨记 +1，是跌记 −1，持平记 0），偏多组减偏空组。
4. 同方向核对用的二分类 Brier：会不会动 (p₁+p₂ − [y 不是持平])²；往哪边动，只在 y 不是持平的行上取 (p₁/(p₁+p₂) − [y 是涨])²，其余行取 0。技能 = 1 − 模型 ÷ 原始对照。

### 3.4 问题二：够不够付价差

1. 用全部行的概率差 s 和上面的权重，取加权的 10% 和 90% 分位点（累计权重第一次达到该比例时的那个值，不插值）。分位点用全样本定一次，抽样时不重新估。
2. 强偏多组：s 大于 0 并且不小于 90% 分位点。强偏空组：s 小于 0 并且不大于 10% 分位点。
3. 每行的后续涨跌取标签里的 `terminal_points`，除以最小变动价位（螺纹钢是 1 元/吨，以输入里的交易规则为准）。
4. 每次多拿的跳动点 = （强偏多组的加权平均后续涨跌 − 强偏空组的加权平均后续涨跌）÷ 2。
5. 同时报全部偏多组减偏空组的后续涨跌之差，以及最强一成的涨跌占比之差。

### 3.5 区间

沿用 R001 的抽样，一处不改：种子 20261113；20,000 次；连续 2 个交易日的循环移动块；92 天日历，没有样本的首日照样占位；各期限、各个量共用同一套抽样索引；type-7 百分位；普通 95%（0.025、0.975）和家族 99.375%（0.003125、0.996875）。每次抽样把 3.3、3.4 的各个量重算一遍。任何一次抽样里某个量没有分母或不是有限数，这个量的区间记 NA，不补抽。
