# 策略研究主线蓝图

版本：20261010-r2；依据读取截至2026-10-10，Asia/Shanghai。本轮交付是本蓝图、[实施计划](IMPLEMENTATION-PLAN.md)、[修复积压](REPAIR-BACKLOG.md)及独立ZCode计划审核；尚未执行新实验、产品开发、数据库/SDK访问、部署或交易。旧[现状审核](../development-blueprint-20261010-r1/REVIEW-AND-PLAN.md)保留为证据快照，本版改变其调度优先级，不覆盖冻结历史。

## 1. 用研究结果组织开发

项目首先要回答：在当时可见的信息、真实可核对的成本、相同整轮风险和连续账户下，哪些行情应对有样本外优势，哪些失败，哪些证据不足？下一项工程工作必须服务于一个明确实验或原合同必须履行的交付。停止沿“先完成整个数据、运行、部署、宏观和管理平台，再开始找策略”的顺序排队。

用户的两项直接要求继续支配路线：“日内交易的短线也要做，所以需要分钟级别的预测”；“针对确定的不同类的行情都要有策略应对，哪怕横盘，也可以做高抛低吸，或者马丁策略来操作，但是需要对行情判断置信度达到一定标准，在无法判断的市场就空仓。”原[总计划](../probability-strategy-v2-plan.md)、[M1–M5详细计划](../devplan-v2/00-开发总纲.md)和[变更007](../devplan-v2/变更申请-007.md)仍是合同；本版缩小每批实验规模，不降低它们的验收门槛。

首版范围保持六品种：螺纹`SHFE.RB`、铜`SHFE.CU`、黄金`SHFE.AU`、豆粕`DCE.M`、铁矿`DCE.I`、原油`INE.SC`；原始合约symbol大小写保留。分钟和日线同时推进，分别训练、校准和评价。分钟使用已完成1分钟bar和因果、会话对齐的5/15/60分钟背景，预测1/5/15/30/60交易分钟；日线预测1/5/20交易日。不能把日线概率缩放成分钟概率。

七入场族为TREND、BREAKOUT、PULLBACK、REVERSION、GRID、MARTINGALE、WAIT/CASH，使用现有14个分钟/日线StrategySpec：`trend/breakout/pullback/reversion/grid/martingale/wait`各自对应`<族>_m1_v2`及`<族>_d1_v2`，不新命名。退出保留独立M3C八族及LEGACY基线：利润阶梯、固定ATR移动保护、波动调整、时间衰减、信号失效/反转、盈利回撤、机会成本、分批。每批只消费阶段允许的少量绑定，未运行的族、期限、品种不能从首版承诺中删除。

## 2. 从现有可用路径开始

已有v1日线探索不是空白：9月8日实际实验记录了809根日线、11个非重叠机会，EV与抽样政策全现金。这是早期探索，不能继承成当前v2正式结论。当前`scripts/research_probability_v2.py`已提供`smoke / walk-forward / final-holdout / reproduce / shadow-replay`五模式，存在14项策略、训练收益路径、连续回放和报告输出；“源码存在”“工程已接受”“实际fit已执行”分别记账。

开发期采用现有`walk-forward`，配置`split_specs.final_holdout=false`、`RunPolicy.purpose=RESEARCH_EVALUATION`、真实输入`synthetic=false`。这会登记实验，不调用最终留出reserve/begin/consume。开发期再分析是报告的证据级别，不是新purpose或第六个CLI模式。现有真实路径仍要求每fold至少252交易日训练、60校准、60滚测；小实验通过减少品种和绑定组合实现，不用短窗口、合成标志或删除期限绕过合同。

主选依赖交付沿已有SC-M1/SC-M2支持链：G3真实硬审及终态custody→G4 Root实际发布/完整验证/terminal release及新lock→G6 M2 exact304消费、最终source/run、原H01–H08/D02和完整独立硬审。SC-M1源304及三工具PASS、SC-M2准备PASS均已存在，G4/G6实际交付尚缺；这些是本路线的真实工作，不再重复相同计划审核。若能选出另一组已经接受、合同兼容且满足本实验输入的冻结源，可用其明确消费者范围开始；须独立审核实际消费的代码、数据和风险，不能把旧局部PASS拼成全节点PASS。

首批只要求所选M1/M2/M3A/M3B/M3C/M4/M5路径的真实接口、时间与账本正确。未消费的APUB实时发布、远端宏观、通用runtime、EX06部署和管理工具的FAIL继续保留，各自承担原义务，但不构成所有离线实验的共同前置。历史分钟研究不等待实时feed验收。数据若不足，只报告不足并为确切缺口准备工作，不先扩大整个平台。

已有源码还有直接影响首批的缺口：DAILY未天然构造跨周期背景，可能在`cross_timeframe=UNKNOWN`处拒绝所有入场及EP1观察。先核选定源是否已修；若仍存在，修复因果背景→状态判定→准入→天然OPEN/训练OBSERVATION全链。本轮明确首批DAILY5入场采用独立`TRADING_DAY20/ATR_1`真实预测作长周期方向背景，MINUTE沿原DAY1背景；缺失、未成熟、过期仍UNKNOWN，不能用较好看的DAY1/DAY5回退。详细时点/身份与反例见实施计划R3，不把语义留给实施者另开规划。不得强置ALIGNED、放松门槛、手工注入观察，或用全现金掩盖结构缺陷。分钟可以先产生结果，但缺日线真实结果时首批未交付。

## 3. 首批预登记矩阵

先按来源、覆盖、成熟尾段、费用/日历规则及既往使用记录选择RB具体合约或合法合约序列。选择不读取收益或按盈利挑合约；RB覆盖不够就记录BLOCKED/INSUFFICIENT，并按同一事前数据成熟规则考察其余品种，分钟和日线准备同时进行。合同序列不自动等于可交易连续价格，换月、复权及相关合约同日分区依原规则。

首批只用一个预先冻结的合法滚动fold及现有简单频率基线，完成下表A/B；有足够数据时按固定60日步进扩展，不能因结果好坏改变区间。训练期冻结特征、阈值、成本、策略参数、随机种子、固定策略和退出绑定；校准区间只校准概率。全部八个预测期限、既有duration集合与六种成本/压力情景保持不变。

| --- | --- | --- | --- |
| A：分钟 | RB；TREND/BREAKOUT/PULLBACK既定30交易分钟经济模板；因果高周期背景；P0合法LEGACY | 同一候选流/预算，最高保守净EV、合格集概率抽样、固定TREND、现金；六情景 | 全五分钟期限预测、校准、实际训练样本、准入漏斗和四政策连续账户 |

A/B用现有`config.strategy_ids`分别选择三分钟ID与三日线ID，建立两个独立config/run_id/split_id；RunPolicy没有frequency或candidate_pool字段，不在同一配置混六项后冒称八个独立账户。各run只有一个事前固定TREND政策，连同BEST_EV/PROBABILITY_SAMPLE/CASH共四种；FIXED填实际strategy及legacy binding hash，其余fixed字段为null。两频率共8个BASE账户组；BASE/FEE_X2/SLIPPAGE_X2/MARGIN_X1_5按各规则完整账户重放，共32结果，GAP/NO_STOP对BASE cohort评价，共16压力结果，总48单元。这些复用冻结样本、模型设定、风险政策和seed，不是48次调参。

固定TREND仍须共同准入，不能为了对照而强开；抽样仅在同一情景的相同合格集合内，失格权重零，固定seed/权重保存，不重置持仓或轮次。各族单独统计候选、阻断、episode和经济证据。若实际仅一族可参与，路由比较退化，应标为策略基准研究、路由优劣不可判定；支持第二种触发族优先于扩退出。C/D每次仅新增一个明确对照；不无限扫参数、更换模型直到出现盈利。

当前M5训练及回放默认选择`legacy`，虽退出库已有`trailing/time_decay`实现，CLI配置尚无显式profile选择；D须先由M5 owner依有效契约完成预登记绑定接线和独立硬审。不能把非legacy hash塞进FIXED字段冒充退出选择能力；这项后续接线不挡A/B基线。

首批输出还必须列出六品种×分钟/日线×全部期限及七入场族的实际状态。RB之外可以为NOT_RUN或有证据的BLOCKED/INSUFFICIENT；不能标为已研究。后续按事前数据成熟顺序扩展六品种，同时保留分钟、日线两条队列。A/B只是开发期小批，未完成全部首版范围及正式/影子验收。

## 4. 研究出口与不可放宽的规则

预测与收益证据分别核对。普通持续概率≥0.70，校准≥200成熟事件/30日期块、高桶误差≤0.05；马丁持续概率≥0.85、冻结止损触达概率≤0.10，校准≥500/60、高桶误差≤0.03。经济证据普通≥100成熟独立episode/30块，马丁≥200/60，按品种、模式、期限判定；ADD短期限另验。相邻分钟、加仓腿和相关合约不制造独立样本。Brier不劣同样本无条件基线，Q05–Q95实测覆盖必须在[0.85,0.95]，边界真实相等不加epsilon/jitter。

经济准入仍为保守净EV严格>0、CVaR95≤整轮预算、压力损失≤冻结权益2%、压力保证金缺口非正。风险上限：整轮0.5%、日损2%、回撤10%、账户保证金40%、单策略10%、单品种15%、相关组25%。最小整数1手不合预算则空仓。压力情景为`BASE/FEE_X2/SLIPPAGE_X2/MARGIN_X1_5/GAP/NO_STOP`，后两者要求诚实暴露风险，不要求每情景盈利。

入场前冻结区间、S0/T0、层级、数量、最晚期限及资源计划；浮亏不是加仓理由，加仓重新验资格。止损不能移远、期限不能延长；M3C只KEEP/REDUCE/EXIT，M4仲裁、成交及唯一账本。普通退出0.65、马丁0.80滞回保留，不给减仓/退出套新开仓门槛。分钟默认不跨交易日，超过可持有窗口的期限阻断入场；夜盘、午休、平今费、收盘禁入/退出均明确。OHLC障碍先后不明保持歧义或保守处理，只有合法细粒度历史能消解。

EP1先冻结真实PayoffTrainingPlan，只让`replay_payoff_training_window`计量候选与退出，再由真实标签/`observation_from_replay`生产匹配观察。保存NO_CANDIDATE、PATH_INCOMPLETE、PRODUCER_EXCLUDED、OBSERVATION及分区排除；未来标签不进入候选或退出决定。第一条observation不等于收益模型READY；必须报告完整样本/准入漏斗。换exit绑定重建exact-key收益与资格，不能继承另一绑定的PASS。

当前实现中，训练模型全无会`StageIncomplete`并输出`error.json`；任一训练收益模型观察为空会记`PAYOFF_TRAINING_EPISODES_NOT_AVAILABLE`及engineering FAIL。两者必须保留，不能改称正常OOS现金报告。天然链错误退原owner修；合法训练产出了观察但证据不足仍报INSUFFICIENT。只有预测/训练及回放路径有效后的OOS零成交，才是完整、诚实的现金研究结果。

连续账户报告净收益、回撤、尾损、日损、库存/保证金峰值、交易及未成交、未完成退出。独立重置episode只用于训练统计，不能累加成复利；跨fold不拼接连续NAV。未知/过期/OOD/冲突/不足时无新增风险，停加仓、取消待开意图并按既定减仓/退出；hold不等于永远持有。全现金是合法行为结果，零收益不是盈利统计PASS。

| 状态 | 使用条件与下一步 |
| --- | --- |
| 工程FAIL / BLOCKED | 实际消费链结构、时间、数据或账本错误；退原owner修复、冻结、新独立硬审；研究结论暂不可用 |
| 统计FAIL | 样本充分但可靠性、覆盖率、基线、净EV或风险未过；保留失败，停止该假设或仅按预登记开发改进 |
| INSUFFICIENT | 样本/日期块/成熟度不足；保留n=0组和原因，不发资格PASS，不为交易降门槛 |
| 研究PASS | 对精确品种/模式/期限/entry×exit/模型/费用版本满足原标准；开发期结果仍不是最终留出/运行资格 |
| NOT_RUN | 没有实际执行；不换成FAIL、INSUFFICIENT或“完成” |

预登记分组任一FAIL聚合FAIL，否则有不足聚合INSUFFICIENT；来源不合格的SCENARIO另列，不伪装历史PIT。发现自然链结构缺陷优先修工程，不能用研究不足代替。

## 5. 由小批推进完整验证

开发滚动结果先用于否证和有限选择。所有失败、全现金及重试登记于现有实验机制，既往v1看过的范围导入为已使用；未知seen状态不能记UNSEEN。正式候选冻结后再进入最终留出：60个可成熟决策交易日、至少20日label-only尾段，并覆盖真实最长持仓/发布日期延迟。尾段不拟合、不增决策。

样本影响闭区间为`[start,max(label_end,holding_end,available_at)]`，边界相等仍purge；分钟embargo≥60交易分钟、日线≥20交易日，并取真实最长影响及联合日历映射较长者。相关合约同一交易日放同一全局分区。全局重叠留出保护不因换品种、源哈希、名称或退出版本重置；第一次读未来标签/价格/经济结果前begin消费，失败仍永久消耗。reproduce仅同输入/代码/配置/seed，`new_statistical_evidence=false`。

新增M3C组合顺序固定为P0契约/legacy/payoff→P1单层trailing/time全平→P2先单层分批、再回归/网格、最后马丁→P3信号退出→P4机会成本。原LEGACY各族行为按原独立版本保留；E0满足自身完整依赖即可研究，不一概排在新增P1/P2后。实际消费新P0契约仍守其公共冻结/审核门；EP1裸OPEN_INITIAL单层路径不解锁ADD/多层。P3/P4可在独占文件prepare，不跳门；P4等待嵌套prefix-only成熟样本，禁止全窗fit后同窗决策。新增复杂模型、更多因子、宏观和退出组合只在简单基线之后提出有理由的增量实验。

后续先做获准历史模拟/离线重放，再完成真实前瞻shadow。`RESEARCH_EVALUATION`反事实账户用于统计，不代表操作准入；`SHADOW_OPERATIONAL`遇统计FAIL/INSUFFICIENT必须NO_TRADE。真实20交易日feed、各品种/会话完整及按时率≥99.5%、P99≤5秒、>120秒禁新仓、UTC误差≤100ms属于完整shadow原门。synthetic/replay不能变成SHADOW_ACCEPTED。

全程`enable_trading=False`、observer=`hold`、broker=`NOT_RUN`，真实send/cancel=0。数据库/SDK/现场操作、服务重启、客户端UI、部署、首单各守已有授权和合同；本轮不执行。SDK历史导出不等于回测，既有离线引擎优先复用。

研究的有效完成是留下可复现的支持、失败或不足证据以及明确未运行范围；策略资格、全v2首版完成、影子接受与实盘许可是不同出口。下一个实验由已取得结果和真实缺口决定，不能再让未使用的平台工程排在全部研究前面。
