## 3. 样本、特征与生产调用边界

主样本每个交易日、每种模式只使用r2原冻结选约证据给出的一个具体合约。原schema固定为`rb-selection-evidence-v1.0.0`，按`(trading_day,duration_seconds)`连接MINUTE/60和DAILY/86400；不得凭空要求`available_at`。依次核验：同键恰有一个entry；`status=SELECTED`；`bootstrap=false`；`previous_trading_day`等于原sessions中紧邻的前一显式交易日；`cutoff_before_first_session=true`且`selection_cutoff_nano`严格小于该交易日第一节start；`selected_contract_id`在manifest中且身份唯一。无前日、bootstrap、缺失、冲突、cutoff不符和合约不符分别计排除，不替补。首日2023-01-03是bootstrap输入，预先排除。以上只是原SCENARIO时点声明的一致性核验，不升级成VERIFIED PIT。

不重新按收益或当日未来成交/持仓量选约。只在所选具体合约内取完整合法历史前缀，历史前缀不要求那一天曾经入选。主样本的可执行性不是本研究结论；原schema或字段与本规范不符时停止该样本规则核验，不猜测适配。

分钟抽样现在固定：按每一显式SessionWindow从开节起的原始1分钟计划网格，把**第5、10、15……根已完成分钟的可用时刻（按end编号：第5根start=开节+4分钟、end=开节+5分钟）**列为候选决策，每节重置序号；仅当该时刻位于该节结束之前或等于结束时保留。计划格子缺失或晚到不补位，不从实际存在的K线重新编号。抽样只减少预测锚点，不稀疏特征前缀或标签窗口。用 `decision=max(bar.end,bar.available_at)`，因此不能把下一分钟才可见的bar回填到收盘。日线每个入选合约每个交易日最多一次，决策为其原日线实际可用且已完成时刻；不得提前到15:00。不在看到TEST结果后改为1/10/15分钟或全量。

全体期限固定：MINUTE **1、5、15、30、60交易分钟**；DAILY **1、5、20交易日**。方向单位为 `(snapshot_id,horizon)`，通过生产`_common_samples`语义选ATR_1；三个屏障方向概率/标签应一致，只计一次。路径附表保留ATR_0.5/ATR_1/ATR_2，不混进方向分母。

固定模型输入为 `factor_registry_v2(duration)` 里全部十个已注册因子：MOM001、MOM003、MOM010、REV001、VOL001、VOL004、VOL005、VOI001、VOI007、VOI009。以生产生成、排序的完整factor_key冻结；不增加SEASONAL或宏观列，不做结果驱动的因子筛选。`build_feature_snapshot`仍接收完整十因子+baseline注册表以供ATR/状态构造；预测向量只用上述十列。任一预测列缺失不插补，按生产向量规则排除并记原因。

调用顺序：按§1保留原v2.1.2身份的严格记录解码/校验（正式loader仍拒绝，未来K45实施须完成其自身输入验证）→ `visible_bars/visible_rule` → `_features`（日线canonical_daily=True）/`build_feature_snapshot` → `fit_regime_reference`、`assess_regime`、`freeze_range` → `build_forecast_requests` → 生产时钟与`assign_splits` → `label_forecast` → `fit_forecast_models`（含其选族、全TRAIN重拟合和校准）→ `predict_market`/`apply_model_set`。不复制因子、ATR、方向阈值、标签、拟合或温度公式。允许小型工具编排和统计汇总，不改src产品代码，不调用M5正式`run_experiment/_fit_fold`入口，也不调用策略、payoff、回放或broker。

## 4. 同训练无条件对照

按每个product×mode×horizon，在与主模型最终拟合**完全相同**的成熟方向TRAIN样本（同features完整性、同去重、同排除）上调用生产 `UNCONDITIONAL_FREQUENCY` 候选拟合/应用逻辑。保留生产Laplace平滑、类别顺序UP/DOWN/NEUTRAL，主对照温度为1：它就是训练历史占比，不从CAL/TEST更新频率。

不能直接取模型集中未选中的unconditional候选：生产 `_run_task_selection` 只保证胜者全TRAIN重拟合，未选中候选可能仍是内部fit样本。工具应通过生产候选函数对合法完整TRAIN重新拟合，并核验样本ID集合与主模型最终训练集合相同。该助手只编排生产私有函数，源码hash固定；不得重写平滑公式或手改训练计数。测试以合成样本验证“内层候选不等于完整TRAIN对照”的情况。

另给一个预先固定的辅助对照：同一TRAIN unconditional，用同一CAL和生产温度候选校准；仅作为“优势是否只来自温度/类别基率调整”的解释，不替换主对照。若选中的主模型就是UNCONDITIONAL且仅温度优于原始占比，不得说特征有预测信息。所有对照在TEST前冻结。

## 5. 主指标、抽样不确定性与判定

三类Brier为每行 `sum_k (p_k-1[y=k])²`（不除3），对数损失为 `-log(p_y)`。每个交易日先在同日成对可评分行内均值，再对日期等权，保持生产选族的日等权方向；同时列总行数/不同日期数/排除数。模型、原始unconditional、校准unconditional使用同一个三方共同合法集合；分别列三者独立可评分数、共同数及差额原因，不能隐藏必要对照缺失。`p_y=0`记无限logloss，不为让分数有限而额外epsilon截断；若生产本身输出有平滑，保持原输出。loss非有限、对照loss为0或无分母时，skill为NA并给原因。

`skill=1-L_model/L_unconditional`。所有8个期限同时报告Brier、logloss及两个skill，不只报较好的期限。每行保留模型和对照原始loss，防止只看比值。

bootstrap固定：**20,000次、seed=20261113**，成对重抽相同的日期块，模型与对照不分开抽。MINUTE用连续2个完整交易日的移动块，DAILY用连续20个完整交易日的移动块，保留同日全部抽样锚点及各期限；日期按显式日历排序，不按有样本的行重新接合。采用循环移动块，抽够原TEST日历日数后截断，缺失日保留零样本占位；每次按重新出现的日等权计算loss比值。各期限共用抽样索引。报告普通双侧名义95%百分位区间及有效重复数。原点loss/skill必须有限且有合法分母；20,000次中每一次都必须有分母、有限且可计算，才允许该指标/对照输出CI。任何一次无效则该CI为NA/BOOTSTRAP_INVALID，保留无分母、非有限及其他错误的各自次数；不对剩余子集算条件化区间，不补抽到凑足20,000次。所有原始/校准对照都共用同一套日期抽样索引。普通百分位数固定type-7：排序后在零起始位置`(n-1)q`的相邻值线性插值，端点取最小/最大；合成测试固定这些规则。20,000次只减少蒙特卡洛误差，不增加原始信息量，不承诺有限样本精确覆盖。

预先加上8期限多重比较控制：Brier技能另报每期限99.375%区间（分位点0.003125/0.996875），Bonferroni覆盖8个方向期限的95%家族范围。普通95%区间是外审要求的主体展示；避免只要8个中碰巧一个略正就恢复策略工程。缺失期限仍算在8项中，不缩减比较数。logloss为一致性核验，不再择优当主指标。

预定结论按以下顺序执行，不把NA当0或负证据，也不择优换指标：

1. **单元不足**：同一模式×期限至少60个共同可评分交易日，TRAIN内层满足原120/30门槛，原始与校准unconditional对照合法，主判定所需loss/skill/CI均有效；任一不满足，单元标`INSUFFICIENT / NOT_ASSESSED`及明确原因。60仅为本研究区间解释门槛，不改产品门槛。日线20日块在短TEST中只有少量有效块，需披露低检验能力。
2. **达到继续研究条件**：上述条件成立，且同一期限Brier家族区间下限>0、logloss普通95%技能下限>0、相对校准unconditional的Brier普通95%下限>0，并且胜者不是UNCONDITIONAL。仅此组合记“在本固定输入与这组特征/模型上出现值得继续检验的信息量”。仍不是策略资格或交易建议。
3. **其余有效组合**：若普通95%Brier下限>0而家族下限不正，记“提示性改善，未达到预设继续条件”；若胜者是UNCONDITIONAL，记“基率/温度校准结果，未显示新增特征信息”；若Brier家族下限正但logloss或校准对照下限不正，记“指标证据不一致，或优势未能排除基率校准解释，未达到预设继续条件”。其余有效而Brier普通下限不正的单元记“未显示信息量”。不得从后两个指标另选一个作主判定。
4. **按模式汇总**：该模式任一单元满足第2项，才可写达到继续研究条件，并同时列其他所有期限。否则有第3项提示/混合结果就按其性质报告而不恢复暂停工程；若所有有效单元Brier普通95%下限均≤0，则固定写“现有特征和模型在这份数据上没有显示出信息量”。若另有不足单元，追加“部分期限无法评估”，不能声称已经证明没有信息量。若所有单元均为第1项，只写“本固定设计没有可评估结果”。

必要对照或CI不足归第1项，不能伪装成第3项负结论。所有8个期限均保留；不同模式之间也不改数据或期限补救。校准好本身不代表经济可用。

## 6. 必报附表

可靠性表按UP、DOWN、NEUTRAL各自固定10个等宽概率箱 `[0,.1),…,[.9,1]`，分别列原始行数、不同交易日数、日等权平均预测概率、日等权实际频率和其差；空箱NA，不按TEST自适应合箱。不把同日数千分钟当独立样本。本10箱表是研究描述性附表，不替换生产CalibrationEvidence既有20箱、政策或资格门槛；每个观察的权重为`1/(有样本日数×该日共同样本数)`，箱内概率/实际频率用这些固定权重归一化，不按箱重新把日期等权。

`P(UP)-P(DOWN)`给固定分位点0/1/5/25/50/75/95/99/100%；使用与主表相同的每观察日等权权重形成加权经验分布，合并相同值后取广义逆`inf{x:F_w(x)>=q}`，q=0/1取最小/最大，不做插值；另附原始行等权（仍用此ECDF广义逆）作为透明对账。中性最大比例主口径为严格大于另外两类；同时报告“并列最大”及“严格或并列最大”，不利用固定argmax顺序隐藏平局。分母与方向主评分集合相同，全部8期限逐一报。

算法表逐product×mode×horizon×task×barrier给选中算法、fit_status、温度、内部development loss、训练/校准日数；再给算法占有效模型cell的比例与按实际预测数加权的比例。失败/无候选单独占位。一个固定split的一类方向任务只有一个胜者，不把候选数当选中算法样本量。

其他生产任务只作描述性附表，不影响主判定：PATH四类三屏障的Brier/logloss；PERSIST事件与STOP_TOUCH双侧、RETURN_BEFORE_BREAK的二分类Brier/logloss；QUANTILE的五分位pinball、区间覆盖/宽度；TIME_UP/TIME_DOWN三屏障及TIME_RETURN/TIME_BREAK的生产离散时间评分、unknown/ambiguous/无范围比例。无合法样本/范围的任务为NA及原因，不补标签、不把AMBIGUOUS算NEITHER。所有附表标SCENARIO/NOT_ASSESSED，不作挑选模型或调整特征依据。
