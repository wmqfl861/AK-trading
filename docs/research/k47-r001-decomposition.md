这是对 K45-R001 已经评过分的同一批预测做的事后拆分，不是新的检验，R001 关于三分类概率的结论不变。

5 分钟的对数损失合计改进为 +0.027446，其中“价格会不会动”为 +0.030278，占 110.32%；“往哪边动”为 -0.002832，占 -10.32%，后者的 95% 区间为 [-0.004746, -0.000933]。

5 分钟偏多组相对于偏空组的涨减跌占比之差为 +0.8793 个百分点，95% 区间为 [-2.3433, +4.3122] 个百分点。

在两端各约一成的强信号组上，按多空两侧各半计算，5 分钟每次的未扣成本分组结果为 -0.3923 跳，95% 区间为 [-0.9136, +0.1362] 跳；按既定成本口径，市价一买一卖至少计 1 跳价差，手续费另计。

表中的改进均为“原始历史占比对照的平均损失 − 模型的平均损失”，使用自然对数；正值表示模型损失更低，不能把它换称为预测准确率的百分点。正文为展示而舍入，全部计算与分类采用随附 CSV 的未舍入值；CSV 中占比和技能仍用原比例。家族区间为 99.375%，继续按 R001 原八个期限控制，没有因为日线不可评估而改成五个。合计与两部分在未舍入值上相加一致，5 分钟的方向部分抵消了部分“会不会动”的改善，所以两部分占比保留大于 100% 和负数，不裁剪到 0–100%。

分支只看事先指定的 5、15 分钟成本区间：其上界分别为 0.13624832680061089 和 0.42814259244613756 跳，均严格小于 1，因而是分支丙。两期限均未达到“显示出方向信息”，K47d 的附加条件也未触发；本批不启动 K48、K49 或 K47d，不恢复暂停的工程项，不另起策略或重新评分。30、60 分钟的成本读法虽为“分辨不了”，不参与 J52 的这一分支选择。“没有显示方向信息”不等于证明不存在任何方向信息，也不外推到其他模型、特征或行情区间。

人口沿用原 R001 的 2024-06-03 至 2024-10-18 检验段，每个期限均为 5,838 行、91 个有样本交易日，三个独立合法人口各为 5,838，排除行数均为 0。92 日交易日历保留没有样本的 2024-06-03。先计算每天的共同人口均值，再对有样本日等权；同一套种子 20261113、连续 2 个交易日循环移动块、20,000 次 bootstrap 同时用于主表复现、五期限和全部十三项统计量，分位阈值不在抽样内重估。

方向读法严格按 J53 的顺序：方向改进的家族下界大于 0 且多空涨减跌占比差的 95% 下界大于 0，才称“显示出方向信息”；否则，两者任一 95% 下界大于 0 为“提示性”；再否则，方向改进的 95% 上界小于 0 为“方向部分为负”；其余为“没有显示方向信息”。成本读法只比较强信号量的 95% 区间：下界严格大于 1 为“付得起价差”，上界严格小于 1 为“付不起价差”，其余为“分辨不了”；等于边界不算跨过。

涨减跌占比是组内 P(UP)−P(DOWN)，主表报告偏多组减偏空组的差，未把中性标签剔除。组均值沿用每行 1/n_d 的原共同人口权重，没有在组内把每一天重新归一化。信号为 p_UP−p_DOWN；强偏多同时满足正信号和全样本加权 q90 门槛，强偏空同时满足负信号和加权 q10 门槛，并列值全部保留，两端各“约一成”不是强制抽取固定行数。

5 分钟强偏多为 569 行、65 日，强偏空为 578 行、60 日；15 分钟相应为 572 行、68 日和 578 行、58 日。强信号的跳数是（强偏多组平均 terminal_points/tick − 强偏空组平均 terminal_points/tick）/2，多空两侧各占一半；它不是按两组样本数量混合的策略平均盈亏，也没有模拟报单、成交、资金占用或复利。手续费、冲击等成本未扣除。
